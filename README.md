# E-Asset Management and Ticketing System (EAMTS)

A web-based system developed as an individual Final Year Project to manage IT assets and support tickets.

## Features
- Asset registration and tracking
- Ticket creation and status management
- User role management
- Database-driven CRUD operations

## Technologies Used
- PHP
- MySQL
- HTML, CSS, JavaScript
- MVC Architecture

## Purpose
This project demonstrates backend development, database integration, and structured software design.
